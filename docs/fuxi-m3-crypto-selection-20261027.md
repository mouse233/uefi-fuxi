# M3 标准能力选择与设备模块交叉审计

UFS 只读能力选择函数以算法编号 0、密钥大小代码 3、4096 字节数据单元
掩码匹配 AES-256-XTS；使用实机六项 capability 的合成输入得到 index 3，
不匹配及非法计数会拒绝。它不装钥、不占用槽位，不能证明密钥可用。

`tools/audit_fuxi_m3_crypto.py` 对三个固定哈希 TWRP 模块做静态审计：
UFS vendor 模块包含算法/密钥大小比较、数据单元掩码筛选及下游调用；
HWKM 路径线性调用点包括初始化、共享内存分配/flush、SCM 设置，并含
逻辑 slot 左移一位。qcom-scm 模块桥注册包含最多四个 VM、数量左移九位，
且会依据内部状态条件性附加 0x1a 标志。局部静态指令顺序不保证运行时
分支路径或 UEFI ABI 一致，也不证明密钥或 bridge 权限。

主机能力选择及 M3 metadata DUN 规划的 ASan/UBSan 检查通过，模块审计
正向和篡改拒绝测试通过。下一候选只做 INFO 查询、能力选择和 M2 只读，
不调用桥操作、装钥或解密。
